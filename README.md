## Startup Weekend Quickstart 

# Intro 
This document will detail the main pitch and findings related to the Startup Weekend competition. The central "Pitch" or buisness idea is a platform that connects Engineering students interested in technical sales with companies looking to hire Sales Engineers. The edge around a company like this is that the scope is focused on technical sales which is not a skill that is provided abundently across very many platforms. As of now the core idea is a platform that is clean and easy to access where a student can make an profile, select what companies they're interested in and work torwards gaining the skills that companies specificly work for when hiring sales engineers. Ideas for tools include technical trainings where students can earn badge, AI powered sales trainings where users can track specific scenerios, as well as other potential features such as live hosted sales case copetitions that employers host. 

## Bridge SE web prototype

The repository now includes a frontend-only React + Vite prototype for Sales Engineering learning, practice, profiles, and company assessments.

```sh
npm ci
npm run dev
```

Use `npm run build` for a production build and `npm run preview` to serve it locally. See [prototype guide](docs/PROTOTYPE.md) for the demo walkthrough, simulated features, and a separate plan for a future Azure avatar scenario. No paid services or deployment are configured.
